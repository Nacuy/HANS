# HANS

React + Vite + Tailwind CSS campus assistant app.

## Installatie

```bash
npm install
```

## Development server starten

```bash
npm run dev
```

De app draait op [http://localhost:8443](http://localhost:8443). Je kunt de poort aanpassen met de `PORT` environment variable.

## Overige scripts

```bash
npm run build    # productie-build
npm run preview  # preview van de build
npm run format   # code formatteren
```
